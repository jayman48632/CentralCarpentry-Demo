# Central Carpentry — Demo Site

One-page demo website for Central Carpentry, an Amish construction company in Clare, MI.

- Plain HTML/CSS/JS, no build step, no framework. About 136 KB total.
- Palette: Navy & Copper. Fonts: Libre Baskerville + Lato (self-hosted).
- Images in `img/` are drawn placeholders. Replace with real photos (WebP, ~1600 px wide).
- Version stamp lives in `version.js` and shows in the footer.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
